# Eisenhower Matrix

Noob vs Senior Programmer



|                   | Urgent                                                                                                                                                                                                                                      | Not Urgent                                                                                                                                                                                                          |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Important**     | **DO (MVP)**<br>- Two-player arena and spawning<br>- Random easy/medium question selection<br>- Multiple-choice UI and server validation<br>- Two unlockable special attacks<br>- HP, basic damage and round timer<br>- Winner announcement | **SCHEDULE (V2+)**<br>- 3v3 teams and FFA<br>- Real code editor and sandboxed judge<br>- Hard/DP questions and ultimate attacks<br>- Edge Case Grenades<br>- Ranked ladder and cosmetics<br>- More maps and effects |
| **Not important** | **DELEGATE (built-in Roblox tools)**<br>- Character movement and physics<br>- Built-in GUI widgets<br>- RemoteEvents and networking primitives<br>- Studio multi-client test runner                                                         | **DELETE (cut)**<br>- Large open world<br>- Pets/trading/currency<br>- Pay-to-win boosts<br>- Custom physics engine<br>- Story campaign and elaborate cutscenes                                                     |

## Why these priorities?

The smallest complete version must let two friends **answer a question, unlock an attack, fight, and find out who won**. Everything beyond that is useful only after this core loop is fun and reliable.
